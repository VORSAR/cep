**2.2 The matcher** (`gate/runner/vulndb.py`):
- **Versions.** `_parse(text) -> tuple` accepts `MAJOR.MINOR.PATCH` with an optional `-PRERELEASE` and an optional `+BUILD` (dropped — `+incompatible` included, on both sides); a leading `v` is stripped first; anything else raises `InvalidVersion(text)`. Order: the core numerically; a version with a pre-release before the same core without; pre-release identifiers split on `.`, numeric identifiers numerically and before alphanumeric ones, then by count — semver 2.0, x/mod's `semver.Compare`. A pseudo-version `0.0.0-20261106192419-47ce03d25ef0` sorts below `0.0.0`.
- **`go_version(tag) -> str`**: `go1.27.4` → `1.27.4`; `go1.27` → `1.27.0`; `go1.28rc1` → `1.28.0-rc.1`; `go1.28beta2` → `1.28.0-beta.2`; anything else raises `InvalidVersion` — including `go1.27.4 X:<experiment>`, **a deliberate difference from x/vuln's `GoTagToSemver`**, which keeps the first field: the gate fails closed, and the pinned go reports no experiment (W0a point 3).
- **`affected(version, ranges)`** (x/vuln v1.9.0 `internal/semver/affects.go:13-90`): no ranges → `True`; no range of type `SEMVER` → `True`; for each SEMVER range: events sorted with `introduced "0"` first and the rest by their version; walking them, `introduced` opens (`"0"` always; else `version >= introduced`), `fixed` closes (`version < fixed`); an event key other than `introduced` and `fixed` raises `UnknownEvent(key)`. True if any range holds the version.
- **`findings(modules, never_built, go_version, entries) -> (findings, faults)`**: for each entry not `withdrawn`, each `affected` block whose `package.ecosystem` is `Go` and whose `package.name` is a key of `modules`, `stdlib` or `toolchain` (both at the tag `go_version`, converted by `go_version()` for matching): if `affected(...)`, a `Finding(id, module, version, fixed, built=module not in never_built)`; `version` is as given (the build list's `v…`, or the go tag `go1.27.4` for `stdlib`/`toolchain`), `fixed` in the database's form (`1.27.5`, no `v`) — the smallest `fixed` event greater than the version in the range that holds it, `""` when none (W0a point 5). Two blocks naming one module give one finding per entry and module. **It never stops at a bad entry** (review DA-S1): an `UnknownEvent` or `InvalidVersion` adds a fault `(id, module, "vulns: <id>: unknown range event <key>")` or `(id, module, "vulns: <id> <module>: version <v> cannot be ordered")` and the walk goes on. Findings sorted by `(module, id)`; faults likewise.
- **A `replace`** (review DA-S2; govulncheck matches at the replacement, `vulncheck.go:131-133`): the row builds `modules` from `gomods.Module`s as `replace_path → replace_version` when both are set, `path → version` otherwise; a directory replacement (`replace_path` set, `replace_version` empty) is not matched and is named in the reason `replaced by a directory: <path> → <replace_path>`. None exists today.

**2.4 `check_db(read, names, stamp, *, root, zip_sha256, now)`** — each fault one line, all collected:

## 3. Lane E2 — the module files, the CI steps, the cap (python-engineer, W2)

**4.1 `install.archive_pins(archive, strip, executables)`** (F1; reviews A-L1, DA-B2): `_install_tool`'s extraction becomes one private helper **`_extract(archive, strip, dest) -> dict[str, int]`** (the `_Extraction` run and its `_Rejected` mapping; it returns the modes and **does not seal**). The installer then writes `.complete` inside `tmp` and calls `_seal(tmp, {**modes, _STAMP: 0o444})` exactly as today (`install.py:272-279`; §0.4). `archive_pins` makes `tempfile.mkdtemp()`, calls `_extract`, `_seal(tmp, modes)`, returns `ArchivePins(manifest.tree_sha256(tmp), {rel: manifest.sha256_file(os.path.join(tmp, rel)) for rel in executables})`, and in a `finally` `_restore_write(tmp)` and `shutil.rmtree(tmp)`. `tree_sha256` skips the root's `.complete` by name (§0.4), so both give the same hash. Equivalence test over a small synthetic `.tar.gz` (an executable, a symlink, a nested directory): the installer's published tree and `archive_pins` give the same tree hash; a `_Rejected` archive leaves no temp directory behind (review DQ-L5).
