Rules (DEVELOPMENT.md:75, ADR-0015 §3.10): exact key sets (file `{schema, note, rule, entries}`; entry `{target, kind, reason, sprint}` plus `ref` for PERMANENT and exactly one of `expiry`/`issue` for TEMP); `reason` ≥ 12 characters; `ref` resolves — an ADR file and, when it has `#anchor`, that heading (the `doclinks` resolver, reused); `expiry` is `YYYY-MM-DD` and red once past (the run's date, injected in tests); `issue` is `#<n>` or an https URL (format only: the gate has no network); `sprint` parses by `sprintid.parse` and names a row at or before the marker's (`Order.reached`); liveness is the reading checker's — each list names its checker, which reports an entry whose target no longer exists (archcheck: a package or file gone; `govulncheck`: an id no longer reported; teeth: a row that now has a proof). ```go

```go
                         // "partition", "partition-keys", "part-key", "step", "select", "rate", "for", "expr",

// ParseFragment parses src as one fragment of kind through lexAll → sliceLexer → ParseFromLexer (trailing tokens
// refused) and lowers it where the lowerer takes that sub-tree; the error carries participle's own message and
// position, never parseError's first-token E-PRAG-001 mapping.
func ParseFragment(kind FragmentKind, src string) error
```
Each kind is backed by a production of the **real** grammar: the 13 existing structs, plus seven named productions added to `grammar.go` (`PatternChain`, `WithinClause`, `AfterMatchClause`, `LateEventsClause` and a keys-only partition embedded so `lower.go` is untouched; `RateClause`, `ForBound` as named pointers with small `lower.go` edits — §0.5b). `Parse` is unchanged in what it accepts: the corpus, golden, fuzz and the T4 grammar differential prove it. **Markers** (R-F F5, rendered by GitHub's own renderer): a fence carries ```` ```cep ```` (a whole program), ```` ```cep-<kind> ````, ```` ```text ```` or ```` ```go ````; an inline span carries an HTML comment **right after** it, no space: `` `within 5 min`<!--cep:within--> `` (parsed), `` `x <> 5`<!--cep-invalid:expr--> `` (must fail), `` `within D`<!--cep-meta:within--> `` (parsed after binding a fixed placeholder table — `D` → `5 min`, `pred`/`filter` → `x == 1`, `A`/`B`/`S`/`T`/`Stream` → declared-looking names, `…` → a step, `${…}` → a param; Q4), `` `e1=A → e2=B[pred]`<!--text--> `` (not grammar input). A comment before the span breaks rendering at a line start (R-F F5). The test, `internal/parser/fragments_test.go` `TestEveryQuotedRuleFragmentParses`, reads `docs/language/SPEC.md` and `SEMANTICS.md` (found by tag, never by line): **an untagged fence is red; a marked span that fails at its kind is red, naming file, line, span and the parser's message; a `cep-invalid` span that parses is red; zero fragments is red**; and, under Q4's recommendation, a rule-like span with no marker is red (the detector of R-F F2, keyword-only spans exempt). SEMANTICS's "illustrative pseudo-syntax" header is annotated to the marker rule. *Stub:* none; lane B owns the Go side and hands the coordinator the marker list.

## 8. Risks and order

1. **The teeth turn every gate edit into two edits.** *Mitigation:* that is the decided cost (decision 5); the `law` kind's one-liner names what moved, so the second edit is one readable line, not noise.
2. **Every `//nolint` is red until S1.1c-3.** *Mitigation:* stated in the failure text; S1.1c-3's plan check makes its `.golangci.yml` the checker's input in its first commit.
3. **The fragment markers become wallpaper.** *Mitigation:* §11 Q4's stricter rule (every rule-like span classified); the test fails on zero fragments.
4. **A nightly that is red for a reason nobody can fix** (a vulnerability with no fix). *Mitigation:* a TEMP entry with an `expiry` on the `govulncheck` list — loud in the notes, red again when it expires.
5. **The aging row lands red.** *Mitigation:* the owner's triage at G0 (Q1, Q9) gives each old entry a decision or a fix in this sprint before the row exists.
