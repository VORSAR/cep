Where they disagree with this file, they win. **Workstream:** **PLAN** · [DESIGN (L0)](DESIGN.md) · [PRIOR-ART (L1)](PRIOR-ART.md) · [SEMANTICS (L2)](SEMANTICS.md) · [SYNTAX (L3)](SYNTAX.md) · [SPEC (L4)](SPEC.md) · [EVAL (L5)](EVAL.md) · [REVIEW (L6)](REVIEW.md).

v1.0 · 2026-10-31 · Precedes engine Phase 1 ([roadmap](../product/02-roadmap.md)): the spec is the normative input for parser/semantics agent waves. Method: `language-design` skill; its artifacts live in this directory. Spec depth is staged: structural semantics (time, emission, patterns) designed for the whole language; normative syntax detail for the MVP subset first, the rest reserved.

| Phase | Work | Artifact | Gate (exit) |

Mapping to the owner's flow: *look at Siddhi* = L1 · *review* = L1 · *modernize* = L0+L2+L3 · *formalise* = L2+L4 · *write it down* = L4. L5–L6 added per skill rule 5: opinions are not evaluation.

**Interim adversarial review (owner-added 2026-10-31), between L2 and L3:** two independent reviewers — (1) semantics red-team (counterexample-backed findings against `SEMANTICS.md`), (2) attack-landscape validation (real 2025–26 attacks researched online, expressed against the semantics; gaps feed the roadmap). Findings in `review/`; every finding ends fixed / forwarded / rejected per ground rules 15–16. Does not replace L6.

Rules in force: semantics before syntax (no keyword before `SEMANTICS.md`); `DESIGN.md` is law each session; every artifact machine-checkable. Scheduling: phases L0–L6 become the first entries in [docs/sprints/sprint-plan.md](../sprints/sprint-plan.md).
