## Gaps
In order of accuracy value:
1. **Nothing re-checks test strength after a sprint.**
   - The committed plant batches (`docs/sprints/*-plants/`) prove that a test catches its defect on the day it lands; nothing re-runs them.
   - A test weakened later passes every row. That is the defect class S1.1c-7 exists to remove.
2. **Concurrency depth.**
   - The PR `race` row runs each package once.
   - Only `internal/runtime` is stress-repeated.
   - `internal/playback` (live and replay, the recorder), `internal/partition` (shards), the root facade (Deploy, Start, Drain) and `io/inmemory` are never repeated under race.
   - No run uses `-cpu 1`, where starvation shows.
   - Tests the sprints flagged as timing-sensitive (TestLiveEqualsReplay, the q2Start group, the recording-overflow tests) run under load only on a developer's machine, as do the gate's threaded Python tests (test_stop_children, test_clock, test_main's workers, the re-index hook's Overlap test).
3. **Input breadth.**
   - Two fuzz targets (the parser, the event decoder).
   - The playback recording reader parses untrusted files and has none.
   - Archcheck's existing `Fuzz` function runs only its seed corpus.
4. **The gate's own code has no coverage floor.**
   - `tools/**` (archcheck, astequal, apidiff, apipartition, shape) and `gate/**` (Python) are outside `coverage-inclusion`'s fixed scope.
   - S1.1c-7 fixed dozens of defects in exactly this code.
5. **Platform and performance.**
   - macOS (the development platform) runs only the determinism job; S1.1c-7's PR 1 met a darwin/linux difference (the race detector needs cgo on linux only) that local runs could not see.
   - No benchmark is recorded anywhere.
