## Guards added (green)

- `TestBreakitDepthLimitsRoundTrip` (playback): payloads 9,999 levels deep (inside an undeclared member, and inside the object attribute) and a typed object 9,998 deep, whose line is 10,000 deep, are recorded and replay byte for byte with equal counters. A typed object one level deeper is refused by Send.
- `TestBreakitConcurrentPayloadsReplay` (playback, run with `-race`): 8 goroutines × 150 SendPayload calls on 4 shards, mixing good, rejected (missing attribute), unknown keys, payload `text_invisibles` with ZWSP, and whitespace-padded payloads. Each caller overwrites its buffer after the call returns. Live and replay agree per key on a two-part keyed rate-limited rule and on a key-less forwarder, with exact StreamStats (Rejected, Unknown and FlagOverrides each 240) and equal RuleStats.

## What I tried that held (no test, or covered above)

- **Multi-part key identity:** `keyT.m` is length-prefixed per part, with -0.0 normalised to +0.0 in both First and Rest. `shardOf` hash collisions only affect placement, not identity. Null and NaN parts are checked before `Offer`.
- **Decoder versus CleanObject:** both resolve duplicate keys, escaped key names (including an escaped `text_invisibles`), lone surrogate escapes and malformed UTF-8 in keys the same way. Raw control bytes in strings are refused, so a recorded line cannot contain a raw newline.
- **Typed round trips (read, not run):** float `-0`, subnormals, `MinInt64`, timestamp bounds (`minRFC3339 == minTimestamp`), and objects that are `ExactObject` but not canonical are refused.
- **Table writes are atomic** (`table.Upsert` checks every row before changing anything), so a failed multi-row write records nothing and applies nothing.
- **The hand-off allocation tripwire** (`TestHandoffAllocationBudget`) was stable over 8 runs each at GOMAXPROCS 1, 2 and 8, and 5 runs under `-race`.
- **Lifecycle (read):** a rejected payload or event after a drain counts in AfterDrain and is not recorded. A second Drain reuses the result. Ticks skip drained apps. Close without a drain writes what is queued and then flushes.
