## Blockers

**DQ-B1 — The mutation runner counts a mutant that does not compile, or fails vet, as red; many of the note's own mutations do not compile.** §3.2 defines red as "the command failed"; `go test` exits non-zero for `[build failed]` and vet failures. Mutations that delete an error check leave the variable unused ("declared and not used"): §8 `appendEvent` "drop each returned error"; §4 item 7 "delete each `if err != nil { return err }`"; §8 `eventRecord` and §9 `expects` "drop each propagation". The `-timeout` backstop ends in `panic: test timed out after 2m0s`, also non-zero, contradicting §10 Q4 ("not a verdict"). **Fix** (§3.2): a fourth outcome, **invalid** (a build or vet failure, or no `--- FAIL:` line), never counted; `panic: test timed out` is **timeout**, not red; red requires `--- FAIL: <the designated test>`; mutation specs must compile (`_ = err`, or delete the whole `if err := f(); err != nil {…}` keeping `_ = f()`); `test_mutate.py` fixtures for a mutant that fails to compile (→ invalid) and a test hanging past `-timeout` (→ timeout).

**DQ-B2 — §2.4 step 2's escape rule reports a cost for a split that adds no allocation (measured on the note's own `AppendValue` split).** "A line present after and not before is a new escape and costs"; every helper that returns its slice parameter adds a `leaking param: … to result` line. Scratch run, §8's split exactly as designed, §2.4's filter and normaliser on `go build -gcflags=-m=2 ./internal/playback`: new after, `leaking param: dst to result ~r0 level=0` ×3 and `leaking param: obj` ×1; gone, none; no new `moved to heap` or `escapes to heap`. §8 P.3 even requires "nothing new in any … 'leaking param' line", which this split cannot meet; the same holds for §6 E.2.3's `appendEscape`, `appendUnicodeEscape`, `appendRune` and every runtime helper taking `*appState`. **Fix** (§2.4 step 2, W0 §3): the cost signal is a new `moved to heap:` or `escapes to heap` line in the original function together with its new helpers, compared as one group; a `leaking param` line is a diagnostic, counted only when a parameter the original function already had now leaks where it did not; one normaliser as a W0 tool (`gate/bench/escapes.py`) with tests (a split adding only `leaking param` → no cost; `&it` to a non-inlined helper → `moved to heap: it` → cost; an inlined helper holding an escape → counted once), used by §4.3, §6 E.3 and §8 P.3.

**DQ-S2 — In validate, two of three poison writes in `names` and all four writes into the resolved App have no test that can fail; §5 §0's "multiset of findings" leaves out the resolved copy.** The sort makes append order unobservable (verified: `validate.go:62-65`; `Diagnostic`'s other two fields are functions of `Code`, `:22-28, :131-134`), but `Check` also returns the copy with every `${param}` resolved (`validate.go:44-46`), read by one in-package test (`units_test.go:254`). Scratch mutations: `names.go:80` poison dropped — red (`TestOneFindingPerDefect`); `names.go:100` `noTarget` dropped — green, also with conformance, plan, parser; `names.go:105` sort-attribute poison dropped — green, also with them; `resolve.go` text operand value changed — green; keyword-set split cut to the first item — green, also with them; duration slot `d.Ms+1` — green in-package, red with conformance; annotation `it.Value = v` dropped — green. **DQ-S3 — The runner writes the tracked file: a killed run leaves the mutant in place, and two runners on one tree corrupt each other's verdicts (both happened in this review).** After SIGTERM, `cmp` showed the scratch `internal/runtime/runtime.go` still mutated ("differ: char 34296, line 965"; Python's `finally` does not run on SIGTERM); killing the parent left `go test` and `runtime.test` running, mutating the file while a second probe ran — every verdict read "timeout" both ways (discarded). **DQ-S4 — The "timeout" outcome and Q4 do not fit, and the cost per mutant is understated.** A test failing at its own deadline already prints `--- FAIL` (red); the backstop firing is the actual timeout. `rtCeiling` is 60 s (`internal/runtime/helpers_test.go:43`), so a mutant red only by hanging costs ≥ 60 s, not §11's "about one second"; a `-timeout` ≤ 60 s turns those into backstop panics. **Fix:** each mutation runs `-count=1 -run '^<test>$'`; `-timeout` above the test's ceiling plus its run time (120 s is enough); outcomes red, green, timeout (not counted), invalid; re-estimate risk 5.

**DQ-S5 — Some mutations are red only by scheduling, and one run proves nothing.** §4 item 15 "move `close(r.stopped)` outside the lock" (red "with the race row and `TestActivateAfterCloseGaveUpIsErrClosed`", inferred); Drain's invariants I1 and I3 have no mutation. **Fix** (§2.3 step 3, Q4): run a scheduling-dependent mutant N ≥ 20 times (`-race -cpu 1,4`), record k/N; a mutant red in none gets a deterministic test or is named "reasoned, not proven" for G1; mutations for I1 (the phase CAS after `awaitRuns`) and I3 (`draining.Swap(true)` after the enqueue).
